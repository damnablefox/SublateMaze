# Spec-0016：专业集蓝图式画布

- 状态：已完成
- 日期：2026-10-22
- 里程碑：M6 后增强

## 目标

1. 专业集详情增加「画布」视图，节点以卡片形式摆放，关系以连线表达；
2. 视觉与交互对齐 UE5.8 蓝图编辑器：深灰网格、带标题栏的节点卡片、执行引脚（白色三角）与数据引脚（彩色圆点）、贝塞尔连线；
3. 节点可拖动，位置保存到 SQLite；画布可平移与滚轮缩放；
4. 从节点输出引脚拖到另一节点即可创建关系，引脚类型决定关系类型；
5. 提供自动分层布局与「适应视图」，首次进入画布时自动排布。

## 非目标

- 不做框选、多选、复制粘贴与撤销重做；
- 不做画布缩放比例与视图位置的持久化；
- 不做移动端手势与触屏专项优化；
- 不改变现有列表视图的能力。

## 数据变更（迁移 011）

`set_nodes` 新增可空列：

| 列 | 类型 | 说明 |
|---|---|---|
| `x` | REAL | 节点在画布中的世界坐标 X，空表示尚未布局 |
| `y` | REAL | 节点在画布中的世界坐标 Y，空表示尚未布局 |

迁移使用 `ALTER TABLE ... ADD COLUMN`，只增不改。

## 关系规则

- `prereq` 走执行引脚，起点与目标都必须是知识点；
- `related` 走数据引脚，目标必须是知识点，起点可以是知识点或载体；
- 载体只能作为数据来源，不能成为前置关系的起点，也不能作为任意关系的目标。

## 接口

### core（`packages/core/src/canvas.ts`）

```ts
interface LayoutNodeInput {
  id: string
  kind: 'point' | 'carrier'
  position?: number
}

interface LayoutEdgeInput {
  sourceId: string
  targetId: string
  kind: 'prereq' | 'related'
}

interface NodePosition {
  nodeId: string
  x: number
  y: number
}

layoutSetNodes(nodes, edges, options?): NodePosition[]
```

布局规则：

- 只使用 `prereq` 边做分层，`related` 不影响层级；
- 无前置的节点为第 0 层，后继层号取所有前置的最大层号 + 1；
- 环中的节点追加到当前最大层之后，保证所有节点都有坐标；
- 同层按节点原有 `position` 排序；
- 默认列宽 360、行高 132。

### storage-sqlite（`ctx.db.sets`）

```ts
listNodes(setId): SetNodeView[]            // 结果含 x / y
updatePositions(setId, positions: { id; x; y }[]): void
```

### sets 插件与 IPC

```ts
sets.updatePositions(id, positions: { nodeId; x; y }[]): SetDetail
```

| 频道 | 入参 | 返回 |
|---|---|---|
| `set:update-positions` | `{ id, positions: [{ nodeId, x, y }] }` | `SetDetail` |

校验：1–500 个位置；坐标必须在 ±1,000,000 内且为有限数；节点必须属于该集合（存储层按 `id + set_id` 更新，忽略不存在的节点）。

### 渲染端

- SetCanvas 组件接收节点、关系与回调；
- 节点坐标缺失时自动使用布局结果并持久化；已有坐标保留；
- 「自动布局」按钮重新布局全部节点并保存；
- 「适应视图」按节点包围盒计算缩放与平移。

## 画布交互

| 操作 | 行为 |
|---|---|
| 拖动节点标题栏或卡片 | 移动节点，松开后批量保存坐标 |
| 拖动空白区域 | 平移视图 |
| 滚轮 | 以指针为中心缩放，范围 0.4–1.8 |
| 从执行输出引脚（白色三角）拖到知识点 | 创建前置关系 |
| 从数据输出引脚（青色圆点）拖到知识点 | 创建相关关系；载体也可作为起点 |
| 点击连线 | 确认后删除关系 |
| 选中节点后点击删除按钮 | 移除节点与相关关系 |
| 工具栏「自动布局」 | 重新分层排布 |
| 工具栏「适应视图」 | 缩放到全部节点可见 |

视觉：

- 画布固定中性深灰（`#1e1e1e`）与 16/128 px 双层网格，浅色与深色主题下保持一致；
- 知识点节点标题栏为蓝图蓝，载体节点为青绿；标题栏含类型图标与状态徽标（草稿/确认/拒绝/失效）；
- 执行引脚为白色三角，数据引脚为青色圆点；`prereq` 连线白色实线带箭头，`related` 连线青色细线无箭头；
- 选中节点显示橙色描边与删除按钮。

## 验收标准

- 列表/画布视图可切换，列表能力不回归；
- 首次进入画布时节点自动排布，位置写入 SQLite；
- 拖动节点后重启应用，位置保持；
- 滚轮缩放以鼠标位置为中心，平移与缩放边界正常；
- 执行/数据引脚可分别创建前置/相关关系，连线点击可删除；
- 载体可通过数据引脚指向知识点，前置关系拒绝载体端点；
- 环、空集合、缺失引用不导致画布崩溃；
- `pnpm typecheck`、`pnpm lint`、`pnpm test` 与 Electron 构建通过；
- 浅色与深色主题下画布均保持蓝图风格。

## 测试点

1. core：链式分层、同层间距、related 不影响层级、环、空输入、载体节点；
2. storage：迁移 11、坐标读写、批量更新与集合隔离；
3. sets 插件：坐标校验、详情返回新坐标；
4. sets 插件：载体数据源规则、前置与目标端点限制；
5. 界面：画布渲染、拖动保存、缩放、引脚连线与自动布局。

### V2：对齐 UE5.8 蓝图（2026-10-22）

- 节点引脚：知识点 4 个（执行输入/输出、数据输入/输出），载体 1 个数据输出；示例集合 3 个节点共 9 个引脚（4 执行、5 数据）；
- 画布视觉：中性深灰 `#1e1e1e`、16/128 px 双层网格、3 px 小圆角卡片、蓝色/青绿标题栏、标题栏类型图标与状态徽标、选中橙色描边；
- 连线：执行边白色 2.4 px 带箭头，数据边青色 1.6 px 无箭头；自动布局列间距由 300 调整为 360，给节点间留出更大空隙；
- 关系规则：`prereq` 两端必须是知识点；`related` 目标必须是知识点，起点可以是知识点或载体；
- 端到端实测：
  - 从载体「来源」数据引脚拖到「群同态」相关输入，新增 1 条 `related` 边，SQLite 中 `set_edges` 记录同步增加；
  - 拖动「群的定义」后坐标从 `(0,132)` 变为 `(0,257.48)`，重启应用后位置、执行边与数据边均保留；
  - 滚轮缩放 88% → 99%，以指针为中心；
  - 列表视图正常显示「相关：抽象代数讲义 → 群同态」，关系可删除；
- 主题：浅色与深色主题下画布均保持同一深灰蓝图风格；
- 测试：216 passed（sets 插件新增 1 个载体数据源与端点限制测试）。
