# Spec-0016：专业集蓝图式画布

- 状态：已完成
- 日期：2026-10-22
- 里程碑：M6 后增强

## 目标

1. 专业集详情增加「画布」视图，节点以卡片形式摆放，关系以连线表达；
2. 视觉与交互参考 UE5 蓝图编辑器：深色网格、带标题栏的节点卡片、左右端口、贝塞尔连线与箭头；
3. 节点可拖动，位置保存到 SQLite；画布可平移与滚轮缩放；
4. 从节点右侧输出端口拖到另一节点左侧输入端口即可创建关系；
5. 提供自动分层布局与「适应视图」，首次进入画布时自动排布。

## 非目标

- 不做框选、多选、复制粘贴与撤销重做；
- 不做画布缩放比例与视图位置的持久化；
- 不做移动端手势与触屏专项优化；
- 不改变现有列表视图的能力。

## 数据变更（迁移 011）

`set_nodes` 新增可空列：

| 列 | 类型 | 说明 |
|---|---|---|
| `x` | REAL | 节点在画布中的世界坐标 X，空表示尚未布局 |
| `y` | REAL | 节点在画布中的世界坐标 Y，空表示尚未布局 |

迁移使用 `ALTER TABLE ... ADD COLUMN`，只增不改。

## 接口

### core（`packages/core/src/canvas.ts`）

```ts
interface LayoutNodeInput {
  id: string
  kind: 'point' | 'carrier'
  position?: number
}

interface LayoutEdgeInput {
  sourceId: string
  targetId: string
  kind: 'prereq' | 'related'
}

interface NodePosition {
  nodeId: string
  x: number
  y: number
}

layoutSetNodes(nodes, edges, options?): NodePosition[]
```

布局规则：

- 只使用 `prereq` 边做分层，`related` 不影响层级；
- 无前置的节点为第 0 层，后继层号取所有前置的最大层号 + 1；
- 环中的节点追加到当前最大层之后，保证所有节点都有坐标；
- 同层按节点原有 `position` 排序；
- 默认列宽 300、行高 132。

### storage-sqlite（`ctx.db.sets`）

```ts
listNodes(setId): SetNodeView[]            // 结果含 x / y
updatePositions(setId, positions: { id; x; y }[]): void
```

### sets 插件与 IPC

```ts
sets.updatePositions(id, positions: { nodeId; x; y }[]): SetDetail
```

| 频道 | 入参 | 返回 |
|---|---|---|
| `set:update-positions` | `{ id, positions: [{ nodeId, x, y }] }` | `SetDetail` |

校验：1–500 个位置；坐标必须在 ±1,000,000 内且为有限数；节点必须属于该集合（存储层按 `id + set_id` 更新，忽略不存在的节点）。

### 渲染端

- SetCanvas 组件接收节点、关系与回调；
- 节点坐标缺失时自动使用布局结果并持久化；已有坐标保留；
- 「自动布局」按钮重新布局全部节点并保存；
- 「适应视图」按节点包围盒计算缩放与平移。

## 画布交互

| 操作 | 行为 |
|---|---|
| 拖动节点标题栏或卡片 | 移动节点，松开后批量保存坐标 |
| 拖动空白区域 | 平移视图 |
| 滚轮 | 以指针为中心缩放，范围 0.4–1.8 |
| 从右侧输出端口拖到左侧输入端口 | 创建关系；只允许知识点节点 |
| 点击连线 | 确认后删除关系 |
| 选中节点后点击删除按钮 | 移除节点与相关关系 |
| 工具栏「自动布局」 | 重新分层排布 |
| 工具栏「适应视图」 | 缩放到全部节点可见 |
| 工具栏关系类型 | 切换新建连线的类型：前置 / 相关 |

视觉：

- 画布区域固定深色蓝图风格（网格背景、深灰卡片、彩色标题栏、浅色连线），浅色与深色主题下保持一致；
- 知识点节点标题栏为蓝色系，载体节点为紫色系；
- `prereq` 连线为实线并带箭头，`related` 为虚线；
- 选中节点显示蓝色描边与端口高亮。

## 验收标准

- 列表/画布视图可切换，列表能力不回归；
- 首次进入画布时节点自动排布，位置写入 SQLite；
- 拖动节点后重启应用，位置保持；
- 滚轮缩放以鼠标位置为中心，平移与缩放边界正常；
- 端口连线可创建前置/相关关系，连线点击可删除；
- 关系类型下拉与列表视图中的关系一致；
- 环、空集合、缺失引用不导致画布崩溃；
- `pnpm typecheck`、`pnpm lint`、`pnpm test` 与 Electron 构建通过；
- 浅色与深色主题下画布均保持蓝图风格。

## 测试点

1. core：链式分层、同层间距、related 不影响层级、环、空输入、载体节点；
2. storage：迁移 11、坐标读写、批量更新与集合隔离；
3. sets 插件：坐标校验、详情返回新坐标；
4. 界面：画布渲染、拖动保存、缩放、端口连线与自动布局。

- 主题：浅色页面中画布保持深色蓝图风格，深色主题下正常；
- 构建：`pnpm typecheck`、`pnpm lint`、`pnpm test` 与 Electron 构建通过；
- 未验证：触屏手势、框选/多选与撤销重做（非目标）。
