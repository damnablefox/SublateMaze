# ADR-0007：暂不实现通用 UI slot

- 状态：接受
- 日期：2026-10-22

## 背景

方案提出插件可向界面注册插槽（侧栏入口、面板、命令）。当前渲染端只加载内置页面，插件通过 IPC 提供数据与操作。

## 决策

M5 不实现任意组件注入的 UI slot：

1. 插件若提供渲染端代码，需要额外的加载、隔离与权限机制，当前架构没有对应的安全边界；
2. 现有页面已覆盖知识库、知识点、笔记、专业集、课程、复习、进度与助手，插件能力可以通过 IPC 被内置页面消费；
3. 过早抽象会增加构建复杂度，且难以在少量插件上验证。

后续扩展采用：

- 渲染端维护「页面注册表」，插件通过 IPC 声明页面元数据与数据接口；
- 增加命令面板（Ctrl+K）聚合页面与操作，而不是注入任意 React 组件。

## 影响

- 新增界面仍需在 `apps/desktop` 内置实现；
- 插件作者通过 `ctx` 服务与 IPC 契约接入，不直接依赖渲染端；
- 未来实现注册表时，需要为页面元数据增加 zod 校验与白名单。
