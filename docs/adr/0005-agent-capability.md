# ADR-0005：Agent 能力与工具边界

- 状态：已采纳
- 日期：2026-10-21

## 背景

SublateMaze 需要与 DeepSeek Harness 同等的 Agent 机制，但它的领域是学习与知识管理，不是编码。直接照搬编码 Agent 的工具会引入无关能力与安全风险。

## 决策

保留 Harness 的循环、工具注册、技能与会话机制，把工具集替换为学习域能力：

- 只读工具：检索、读取载体、掌握度分析、路径推荐；
- 草稿工具：生成测验、摘要，不写正式数据；
- 提交工具：创建笔记、调整计划、抽取知识点，必须用户确认；
- 危险工具：删除实体，默认不注册，需二次确认；
- 编码类工具（终端、沙箱、computer-use）不做默认能力，未来以可选插件提供。

Agent 的决策函数在 M0 由调用方注入；接入 `ai-provider` 后由模型生成。循环、确认与审计是真实实现。

## 后果

- Agent 可以离线测试，不需要真实模型；
- 所有写操作可审计、可回放；
- 工具权限是应用层约束，不是沙箱；第三方插件仍需谨慎启用。
